# 포근트립 — 승인된 기획의 구현 기준

2026-11-25. 사용자 요청: 누구나 쓰는 일본 전역 여행 서비스, 귀여운 다이어리 디자인, 명소/맛집 추천, 일정 생성/편집/저장/공유, Google Maps 지도/실제 이동 루트. 월 운영 예산 약 30,000원. Google Cloud 계정 미준비이므로 설정 안내 제공.

React/TypeScript + Sites Vinext starter + Cloudflare D1. 기존 사용자 파일과 무관한 새 사이트 디렉터리로 격리한다. 기존 저장소의 staged 변경을 건드리지 않는다. Maps 링크만 쓰는 대안은 기능 요구를 충족하지 못하므로 실제 Maps JavaScript/Places/Routes API를 구현한다. Google 비밀 키는 서버 환경변수, 지도용 공개 키는 API/도메인 제한을 전제로 사용한다.

크림/살구/말차 팔레트, 직접 그린 SVG 포근트립 캐릭터, 사진 카드, 날짜 탭, 지도/일정 2열. 모바일 지도 전환. 데모 상태를 항상 알리고 가짜 평점/시간/경로를 제시하지 않는다. API 미설정 시 실제 지도 대신 명시된 일러스트와 예시 장소 제공.

월 20,000원 보수적 API 예약장부 + 10,000원 기타 비용 여유. 무료 할당량을 차감하지 않고 검색 100원, 장소 상세 60원, 경로 25원, 지도 생성 25원으로 보수적 예약한다. 실제 청구 한도 보장은 불가. D1 원자적 UPSERT로 경합 차단, 한도 도달/DB 장애 시 유료 API 실패 폐쇄, 공개 사용량 제한. 지도 키가 브라우저에 노출되므로 Cloud 할당량/도메인 제한 필수. 실제 결제 계정은 사용자가 준비해야 한다.

서버 장소 검색 결과로 중복 없는 일정 구성, 식사/카페 슬롯과 가까운 순서 사용, 입력된 숙소를 출발점으로 반영. 이동시간은 Routes 응답에 한해 표시. 대중교통은 구간별 요청. 개장시간은 방문 날짜에 맞는 데이터가 없으면 미확인 표시. 저장/공유는 장소 ID와 사용자가 정한 옵션만 지속 저장하고 Google 정보는 재조회한다. 익명 공유 링크 소유자는 열람 가능, 소유/편집 토큰은 분리한다.
