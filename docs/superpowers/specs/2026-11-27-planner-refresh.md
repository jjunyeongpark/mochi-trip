# 포근트립 여행 화면 개선

사용자가 2026-11-27 확인한 화면 시안과 지역 전체 강조 수정안을 실제 기존 사이트에 적용하도록 승인했습니다.

1. 처음 제공한 GIF를 프레임별 재분리한 진짜 투명 WebP 두 개를 400px 기준으로 인사·완료 장면에 사용합니다. 실시간 색상 제거를 없앱니다.
2. 휴대폰에서는 지도와 사진 시간표를 한 화면에 배치하고 일정을 스크롤하는 동안 지도가 보이게 합니다.
3. 일정·검색·찜·지도 장소 선택은 사이트 내부에서 핀을 강조하고 상세 화면을 엽니다. 외부 지도는 사용자가 명시적으로 선택하는 보조 링크입니다.
4. 날짜별 고유 색의 실제 경로를 표시합니다. 전체 날짜 보기와 선택 날짜 보기를 제공하며, 미확인 경로는 실제 길찾기처럼 꾸미지 않습니다.
5. 여행지 발견에서 일본 지역 전체를 호버·포커스·클릭·터치로 강조합니다.
6. 도착·체류·이동·숙소 복귀 시간표를 표시합니다. 미확인 이동은 예상으로 명시합니다.
7. 숙박 지역 추천과 실제 Google 숙소 검색 결과를 제공하고 선택 숙소를 일정 출발·복귀에 연결합니다. 없는 가격·예약 가능 정보는 생성하지 않습니다.
8. 여행지 발견, 테마별 여행, 여행 만들기, 숙소 찾기, 나의 여행 메뉴를 실제 동작과 연결합니다.
9. 대표 도시는 기존 네 곳에 삿포로와 나하(오키나와)를 추가하여 여섯 곳으로 만듭니다.
10. 일정 카드에 해당 장소의 Google 사진을 표시합니다. 사진이 없으면 카테고리 대체 화면을 쓰고 사진 제공자 출처를 표시합니다.

기존 공개 범위·사이트 주소·API 비용 보호·저장/공유 기능을 유지합니다. Google 제공 콘텐츠는 영구 저장하지 않고 저장/공유에는 ID만 기록합니다. 실제 사이트에 게시하는 것까지 승인된 범위입니다.
